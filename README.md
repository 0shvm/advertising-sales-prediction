# Advertising Sales Prediction using Linear Regression

## Objective
Analyze how advertising budgets across different media channels (TV, Radio, Newspaper) influence product sales.

## Dataset
The dataset contains advertising expenditure data across three marketing channels:
- TV advertising budget
- Radio advertising budget
- Newspaper advertising budget

Target variable:
- Sales

Total observations: 200

## Exploratory Data Analysis
EDA was performed to understand relationships between advertising budgets and sales.

Key insights:
- TV advertising shows the strongest relationship with sales.
- Radio advertising also contributes significantly.
- Newspaper advertising shows weaker influence.

## Model Used
Linear Regression was used to model the relationship between advertising budgets and sales.

## Features
- TV
- Radio
- Newspaper

Target variable:
- Sales
